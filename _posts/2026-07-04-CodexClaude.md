# 비개발자로서 github 블로그에 대한 인상 

W7l.github.io 블로그를 2016년 부터 운영하기 시작했습니다. 

맥북  터미널에 낮설은 루비를 설치하고 힘들게 블로그를 생성했습니다.  

완벽한 소스코드 관리는 자신 없었지만, 무한한 커스터마이징 매력에 끌렸습니다. 

<img src="/images/2026-07-04-CodexClaude/github.png" alt="github" style="zoom: 67%;" />

&nbsp;



## 깃허브 블로그를 덮다

로칼 상에서는 글을 작성하였지만 웹상에 배포를 못하는 상황을 맞았습니다. 

에러 발생을 해결 할 수 없었습니다. 

개발자는 커녕 기본 지식조차 없는 상태에서  github 는 오르기 힘든 큰 산 이었습니다.

이후  9년 동안  github 블로그 덮고 잊었습니다. 



![noway](/images/2026-07-04-CodexClaude/noway.png)

&nbsp;

## 네이버 블로그 경험

그 기간 동안 직장퇴직, 새로운 개업으로 바쁜 시간을 지냈습니다. 

개원  홍보를 위해 네이버 블로그를 작성하였습니다.

그러나 네이버 블로그는 저 로서는 받아들이기 힘든 면이 있었습니다. 

내용, 형식의 제한을 받는 것이 가장 어려웠습니다. 

&nbsp;



## 깃허브 블로그를 다시 시작하다 

깃허브의 **무한한 커스터마이징**의 매력을 잊을 수가 없었습니다. 

&nbsp;

## 깃허브 블로그의 유리한 점

<div class="notice--danger">
<h4>깃허브 블로그의 유리한 점 (네이버 브로그 대비)</h4>
<ul>
    <li>개발자 이력서 활용: 깃허브 블로그에 글을 작성할 때마다 커밋(Commit) 기록이 남아 개인 저장소에 남아있습니다.</li>
    <li>마크다운(Markdown) 기반: 코드를 작성하고 배포하는 과정이 **마크다운 문법**으로 이루어져 있어 일반적인 텍스트 에디터보다 문서 작성과 코드 가독성이 뛰어납니다.</li>
  	<li>절대적인 자유도: 블로그의 디자인, 레이아웃, 기능 등 모든 요소를 사용자가 원하는 대로 직접 수정하고 제어할 수 있습니다.</li>
  	<li>데이터 소유권: 네이버 플랫폼에 종속되지 않고 자신의 리포지토리에 모든 데이터를 직접 소유할 수 있어 데이터 백업과 이전이 매우 자유롭습니다.</li>
  	<li>광고/수익 제한 없음: 블로그 내에 구글 애드센스 등 원하는 광고 시스템을 자유롭게 연동하여 수익을 창출할 수 있습니다.</li>
    </ul>
</div>

# 네이버:  생태계 최상위 강자

국내 블로그 생태계에서 네이버는 절대적 강자 입니다. 

때로는 블로그의 운영 목적이 업체의 홍보, 광고를 지향합니다. 

깃허브 블로그는 네이버 생태계를 벗어나 있습니다. 따라서 깃허브 블로그는 홍보, 광고 역할을 하기 어렵습니다. 

네이버 스마트 플레이스에 깃허브를 링크하는 것 조차 불가하기 때문입니다. 

&nbsp;

## 네이버 생태계에서 깃허브는 외롭다

&nbsp;



다음은 네이버 스마트플레이스에 **URL 추가** 관련 입니다. 

 <img src="/images/2026-07-04-CodexClaude/naverSmatPlace.png" alt="naverSmatPlace" style="zoom:33%;" />

윗그림에서 카페, 예약, 밴드, 스마트스토어는 모두 **네이버 카페, 네이버예약** 만으로 배타적 등록됩니다. 

페이스북, 인스타그램, 유튜브 외에는 **비 네이버 링크는 불가**합니다. 

URL 입력에서 튕겨 버립니다. 결과적으로 깃허브 블로그가 네이버 스마트 플에이스에 링크 될 수 있는 방법이 차단되고 있습니다. 

네이버 블로그에서 깃허브 블로그를 **링크 가능**한지는 아직 확인하지 못했습니다.
