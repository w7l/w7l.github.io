어깨 회전근개 힘줄 병변에 관계되는 용어인 건증(tendinosis)과 건병증(tendinopathy)을 감별함이 중요합니다. 이  두 용어는 병리학적 정밀도 수준이 다릅니다

&nbsp;



# 건병증 (tendinopathy)





- 포괄적 임상 용어
- **정의**: 건(tendon)에 통증·기능 이상을 일으키는 모든 병적 상태를 통칭하는 **상위 개념(umbrella term)**
- 조직학적 기전이 염증인지 퇴행인지 구분하지 않고, "건에 문제가 있다"는 임상적/영상의학적 소견을 나타낼 때 사용
- MRI·초음파 판독에서 정확한 조직학적 확진 없이 건의 이상소견(비후, 신호강도 변화 등)을 기술할 때 흔히 사용하는 용어
- Supraspinatus tendinopathy = 극상근건에 병리학적 변화가 있다는 포괄적 표현 (원인 불문)





&nbsp;

&nbsp;



# 건증(tendinosis)



- **정의**: Tendinopathy의 하위 유형 중 하나로, **비염증성 만성 퇴행성 변화**를 가리키는 구체적 진단
- 조직학적 특징: 콜라겐 섬유의 배열 이상(disorganization), 세포외기질(ground substance) 증가, 신생혈관 형성(neovascularization) — 염증세포 침윤은 뚜렷하지 않음
- 과거 흔히 쓰이던 "tendinitis(건염, 염증성)"과 대비되는 개념으로, 실제 만성 건 병변의 대부분이 염증이 아니라 퇴행성(tendinosis)이라는 사실이 밝혀지면서 널리 쓰이게 됨
- Supraspinatus tendinosis = 극상근건의 만성 퇴행성 변화 (파열은 동반하지 않은 상태)

&nbsp;

&nbsp;



# 요약 비교

| 구분           | Tendinopathy                           | Tendinosis                                           |
| -------------- | -------------------------------------- | ---------------------------------------------------- |
| 범주           | 포괄적(umbrella)                       | 특정 하위진단                                        |
| 기전 특정 여부 | 불특정 (염증/퇴행 모두 포함 가능)      | 특정 (비염증성 퇴행)                                 |
| 사용 맥락      | 임상/영상 소견 기술 시 일반적으로 사용 | 조직학적 확진 또는 만성 퇴행 변화가 명확할 때 사용   |
| 관계           | 상위 개념                              | Tendinopathy의 하위 유형 (tendinosis ⊂ tendinopathy) |







&nbsp;



# 정리

 모든 tendinosis는 tendinopathy 입니다. 

그러나  모든 tendinopathy가 tendinosis는 아닙니다(급성 염증성 변화, 부분파열 등도 tendinopathy에 포함될 수 있음). 

임상에서는 정확한 조직학적 확인 없이 "tendinopathy"라는 포괄적 표현을 쓰는 경우가 많습니다. 

그러나, 만성 퇴행성 소견이 현저할 때  "tendinosis"라는 더 구체적인 용어를 사용합니다.
